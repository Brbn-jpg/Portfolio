# https://brbn.pl/robots.txt
#
# Policy: this is a personal portfolio. Its whole purpose is to be read, indexed
# and quoted — by search engines and by AI systems alike. Retrieval bots produce
# the citations; training bots let a model answer "who is Jakub Kuznicki" without
# retrieving anything at all. Both are wanted, so both are allowed.
#
# The one exception is /cv/, which contains personal contact details that do not
# belong in a search index or a training corpus. The CVs stay downloadable from
# the site itself — robots.txt does not affect direct navigation.
#
# NOTE: robots.txt groups are NOT additive. A crawler obeys exactly one group —
# its most specific User-agent match — and ignores * entirely. That is why
# `Disallow: /cv/` is repeated inside every named group below.

User-agent: *
Allow: /
Disallow: /cv/
